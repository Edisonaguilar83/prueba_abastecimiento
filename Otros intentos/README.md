# Optimización de Abastecimiento — Intento Inicial

## Descripción

Este proyecto corresponde a un primer intento de desarrollar una solución para optimizar el abastecimiento a partir de información histórica de ventas.

## Desarrollo

- Preparación y organización de los datos históricos.
- Análisis de ventas por tienda, producto y periodo.
- Cálculo de unidades vendidas y agregaciones.
- Construcción de un modelo en Excel para analizar el comportamiento de las ventas.
- Exploración de una estrategia de abastecimiento basada en la demanda histórica.

## Resultado

El desarrollo no logró convertirse en una solución de optimización funcional. El análisis permitió estructurar y explorar los datos, pero no fue suficiente para generar recomendaciones de abastecimiento confiables. Esto debido a la validación de métricas como el RMSE que fue de mas de 40.

## Limitaciones identificadas

- Falta de variables necesarias para modelar el abastecimiento.
- Ausencia de un modelo robusto de pronóstico de demanda.
- No se consideraron restricciones reales de operación y abastecimiento.
- El resultado quedó principalmente en un nivel descriptivo.

## Conclusión

Este proyecto representa un **prototipo exploratorio** que permitió identificar las principales necesidades y limitaciones del problema de abastecimiento y sirvió como punto de partida para plantear una solución más robusta.
